# Балансировщик на языке golang

## Как запустить:
Для начала перейдите в папку проекта(если вы не в ней)
Затем скопируйте example-config.yaml, дав название config.yaml, а также отредактируйте его под себя. Поле port означает порт запуска балансировщика, а в секции backends вы можете указать список всех ваших серверов в формате `название: "адрес"`. Балансировщик автоматически подтянет и зарегистрирует каждый из них, независимо от их количества.

## Пример конфигурации (Взято из example-config.yaml):
```yaml
server:
  port: ":8080"
backends:
  server1: "http://localhost:8081"
  server2: "http://localhost:8082"
  server3: "http://localhost:8083"
```

## Запуск приложения:
После того как файл настроек создан, выполните в консоли:
```bash
go run cmd/main.go
```
